# Rebooting a Hero: A Timeline of the Spider-Man Films

An interactive TimelineJS timeline of every Spider-Man film from 2002 to 2026, and the deals and decisions behind each reboot.

**Live site:** https://lukekav48-jpg.github.io/my-first-site/

## Files

- `index.html`: the page, with an introduction, a legend, the argument, and sources.
- `timeline.json`: the timeline data (slides, eras, media, colors). Edit this file to change the timeline.

Published with GitHub Pages from the `main` branch.
