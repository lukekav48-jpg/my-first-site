Spider-Man Across New York

This is a map of every Spider-Man movie from 2002 to 2026. Each pin is where the biggest fight in that movie happens, and you can follow Spider-Man as he goes from one fight to the next. Almost all of them take place in New York, but one of them goes to London and two of them happen in other universes.

      About this project

      When I started this project it was a regular timeline of the Spider-Man movies. While I was putting it together I noticed that almost every big fight happens somewhere you could actually find in New York, like the Queensboro Bridge, Times Square, and the Statue of Liberty. Most Spider-Man timelines are just a list of release dates, so I wanted to show the movies as places instead. Each stop on the map is where the main fight of a movie happens, so going through the whole map takes you through every Spider-Man movie from 2002 to 2026. It also shows how the same city keeps getting used over and over again across four different actors and four different film series.

      My first version of this project was built with TimelineJS. It worked, but a timeline can only show when something happened and not where it happened, so I decided to switch to a map. The map is made with Leaflet, which is a free tool for making interactive maps, and the background is Esri's dark gray map, which uses data from OpenStreetMap. All of the information for each stop is saved in one file called stops.json, so if I want to change something I only have to edit that one file. The site is hosted for free on GitHub Pages. I don't really have any coding knowledge, so I used AI to help me write the code and turn my ideas into something that actually works.

      For the design I went with a dark map so that the pins and the webs would stand out. Each film series has its own color, and every pin has a number on it so you don't have to rely on the colors to know what order the movies go in. Instead of drawing a line between the stops, Spider-Man leaves little web logos behind him, kind of like footprints, that point toward the next stop. When he lands, a clip of the fight pops up right next to the pin and starts playing, while all of the info about the movie stays on the side. Far From Home is the only movie where the fight leaves New York, so I gave London its own small map in the corner. The two Spider-Verse movies have a glowing ring around their pins since they take place in other universes.

      I also wanted to make sure anyone could use the map. You can get around with just a keyboard by using the arrow keys, and every button and pin can be reached with the Tab key. If someone is using a screen reader, it reads out the movie and the place every time the stop changes. The "View as a list" button shows all eleven stops as plain text, and the "Reduce motion" box turns off the animations and stops the clips from playing by themselves. That box turns on by itself if your device is already set to reduce motion. You can close a clip with the X or the Escape key, and the site works on phones too.

      Sources

      • I got the plot and fight details from each movie's Wikipedia page. Brand New Day just came out, so for that one I used Variety and SuperHeroHype.
      • The filming locations came from MCU Location Scout for the Spider-Man 2 train fight and Pier 56, and from The Worldwide Guide to Movie Locations for Spider-Man 3.
      • The box office numbers are from Box Office Mojo and The Numbers, and I rounded them.
      • The fight clips are embedded from YouTube, and each stop says which channel the clip came from. All of the movie footage belongs to Sony Pictures and Marvel Studios.
      • The map tiles are from Esri, with data from Esri, HERE, Garmin, and OpenStreetMap contributors.
